## Install

- **Windows**: download `cordfast-v…-x86_64-pc-windows-msvc-setup.exe` and run it (no administrator prompt).
  Or extract the `.zip` into a folder of yours and open `cordfast.exe`.
- **Linux**: extract the `.tar.gz` and run `cordfast` (needs `libxkbcommon-x11`, `libasound2` and OpenGL).

Copies installed this way update themselves to later signed versions.

## What's new

- **Your voice sounds clean**: no more robotic gaps or clipping when you talk.
- **Games**: one game at a time, the one in front, with Discord's name for it (PUBG no longer shows twice). Settings → Registered Games lists every game you played.
- **Keybinds** match Discord's: Return to Connected Voice Channel is Ctrl+Alt+Left, and there are new ones to go to the current call, copy the channel link, collapse all categories and zoom.
- The microphone reaches the call, and another of your clients no longer disconnects CordFast or hangs it on "Connecting".
- Settings in Discord's new layout, Discord's expression picker, Vencord-style plugins and the interface in eight languages.
